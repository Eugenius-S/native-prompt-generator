# Styling Drafts

Put small styling fragments here when adding:
- outfit variants
- hairstyle presets
- hair color extensions
- makeup archetypes

Keep them narrow:
- one topic per file
- include `status` and `source`
- do not mix unrelated experiments in one fragment

Examples:
- `modest_makeup_seed.json`
- `male_hair_seed.json`
- `coastal_outfits_seed.json`

Recommended split:
- `modest_appearance_seed.json` for safe women additions
- `male_appearance_seed.json` for male-safe additions
- one future file for one narrow theme only

Practical rule:
- if you are testing 3 new hairstyles, add one tiny file
- if you are testing 20 unrelated ideas, split them into multiple files
- only move approved records into the core `styling.json`
