# Subject Drafts

Put subject-side additions here when adding:
- new ethnicity presets
- subject descriptors
- identity-safe additions that should be reviewed before going live

Keep fragments small and explicit.

Examples:
- `male_ethnicity_seed.json`
- `european_subgroups_seed.json`

Recommended split:
- one file for ethnicity additions
- one file for body/beauty additions
- one file for experimental or excluded-default groups

Practical rule:
- if you only add a few subgroups, do it in one tiny file
- if you are changing multiple identity axes, split them by topic
- keep `status` and `source` on every new record
