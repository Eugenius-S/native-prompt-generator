# Product

## Register

product

## Users

Local ComfyUI users who generate batches of native-structure photo prompts and tune content banks, presets, and prompt controls while testing image output.

## Product Purpose

Native Prompt Generator creates configurable prompt batches for realistic AI photo sessions. Success means the user can quickly steer subject, spicy level, styling, locations, outfits, poses, and anti-repeat behavior without editing engine code.

## Brand Personality

Precise, calm, technical. The interface should feel like a focused local creative tool, not a marketing site or toy generator.

## Anti-references

Avoid SaaS landing-page visuals, decorative glass cards, noisy neon dashboards, playful toy UI, over-rounded nested cards, and controls that look different without a functional reason.

## Design Principles

- Keep the generation workflow fast to scan.
- Make the current choices and output state obvious.
- Preserve useful density without flattening hierarchy.
- Use restrained visual polish only where it improves task flow.
- Treat debug, history, and line-bank help as utility surfaces.

## Accessibility & Inclusion

Target readable contrast, visible keyboard focus, semantic controls, and reduced-motion-safe transitions.
